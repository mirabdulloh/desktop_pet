# Marin character pack

This folder holds her name, lines and timing. It contains no artwork or model, because
Marin Kitagawa (*My Dress-Up Darling*) is a copyrighted character.

## Getting a model

Use a `.vrm` model you have permission to use:

- Commission an artist or 3D modeler
- Buy one whose license allows personal use, for example on BOOTH
- Make your own in [VRoid Studio](https://vroid.com/en/studio), which exports VRM

Then choose **Import VRM Model…** from the tray. The file is stored in the app's data
folder, and `*.vrm` is git-ignored so it can't be pushed to the public repo by accident.

Models with the standard `happy`, `surprised`, `relaxed` and `blink` expressions and
spring-bone hair get the full effect.
